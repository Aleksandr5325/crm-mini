# CRM-mini: воронка продаж

Учебный проект по дисциплине «Основы проектной деятельности» (кейс №3 — CRM-mini: лиды и воронка продаж).

Система ведёт лиды по стадиям воронки, строит отчёт по конверсии и длительности
стадий и поддерживает идемпотентный импорт данных из CSV.

## Архитектура (два контура)

```
[Веб-интерфейс] ── CSV (текст) ──▶ [1С: HTTP-сервис] ── JSON ──▶ [Go API] ──▶ PostgreSQL
       │                              (учётный контур)         (оперативный контур)
       └────── REST: лиды, стадии, отчёт, экспорт ───────────────────┘
```

- **1С (`/1c`)** — учётный контур: справочники (лиды, источники, сотрудники),
  регистр истории стадий, отчёт «Дашборд», импорт и экспорт CSV. Роли:
  Менеджер, Руководитель ОП, Аналитик, Администратор.
- **Go API (`/`, `main.go` + `/internal`)** — оперативный REST-бэкенд: CRUD по
  лидам, смена стадии с серверной валидацией правил воронки, история стадий,
  идемпотентность импорта (по SHA-256 тела запроса), хранение в PostgreSQL.
- **Веб-интерфейс (`/site`)** — SPA на нативном JS (ES-модули): импорт CSV,
  список лидов, канбан-доска воронки (drag-and-drop), отчёт с экспортом CSV.
  Разграничение по ролям: Пользователь / Работник / Менеджер.

## Запуск

### 1. PostgreSQL
Нужны роль `postgres` (пароль `admin123`) и база `crm` (см. `dsn` в `main.go`).

### 2. Go API
```bash
go run .            # поднимает сервер на :8080, создаёт таблицы автоматически
```

### 3. Веб-интерфейс
```bash
cd site
python3 -m http.server 5500
```
Открыть http://localhost:5500

### 4. Загрузка данных
Через веб-интерфейс (вкладка «Импорт CSV») — полная цепочка через 1С,
либо напрямую в Go для разработки:
```bash
curl -X POST http://localhost:8080/import/leads \
  -H "Content-Type: application/json" --data-binary @testdata/seed_leads.json
```

## Стадии воронки
`new → qualified → proposal → won | lost`
Движение только вперёд; `won`/`lost` — терминальные. Правило проверяется на сервере.

## Структура
```
.
├── main.go              # точка входа, роутинг, подключение к БД
├── internal/
│   ├── handlers/        # HTTP-обработчики (лиды, импорт, источники)
│   └── models/          # модели данных (GORM)
├── 1c/                  # выгрузка конфигурации 1С
│   └── openapi.yaml     # спецификация HTTP-сервиса 1С
├── site/                # веб-интерфейс (SPA)
└── testdata/            # тестовые данные
    └── seed_leads.json  # тестовый набор данных
```
